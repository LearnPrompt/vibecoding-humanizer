# svg 模式：矢量图去 AI 味

由 [SKILL.md](../SKILL.md) 路由到这里。适用于图标、插画、动画 SVG（SMIL/CSS）和动态海报里的矢量元素。动态海报整体按 [html 模式](mode-html.md)，本文件只管其中的 SVG 部分。

先分清产物类型：**单色图标**、**图标集**、**多色插画/海报**、**动画 SVG** 的要求不同，下面每条都写了适用范围。

## 生成时的约束

沿用共用规则：约束输出格式、颜色数量、风格锚点和图标系统（统一 viewBox、stroke 宽度、端点和圆角规则）。复杂图形可以分步生成，先构图后细节。

## 后期清理条目

### 1. 无意义的背景与隐形层

**识别信号**：覆盖整个 viewBox 的白底 `<rect>`；透明度为 0 或被完全遮住的形状。

**修改**：删掉无意义的白底和隐形层。

**何时保留**：背景是画面的一部分（天空、海报底色）、被 mask/clip 引用、或被动画使用时不删。

### 2. 路径节点过多

**识别信号**：一条简单曲线几十个点；轮廓抖动。

**修改**：Illustrator 的 Object > Path > Simplify，或在 [SVGOMG](https://github.com/jakearchibald/svgomg) 等工具里处理后人工检查外观。

**注意**：降低小数精度（precision）只是缩短坐标数字，**不减少节点数**；两者分别处理，压缩后都要和原图对比外观。

### 3. 一条线被拆成多个重叠形状

**识别信号**：同一笔画由几段重叠路径组成，半透明时重叠处变暗。

**修改**：在 Figma/Illustrator 里做布尔合并（Boolean / Union）。

### 4. 硬编码颜色

**适用范围**：**单色图标**。把 `fill="#000000"` 等换成 `currentColor`，方便 CSS 控制和暗色模式。

**不适用**：多色插画、品牌色明确的海报、渐变与配色本身是设计的图。不要一律改单色。

### 5. 冗余代码与分组

**修改**：用 SVGO / SVGOMG 清理生成时留下的注释、冗余属性；按功能分组并命名（如 `Icon_*`、`wheel-front`）。

**何时保留**：被 CSS、JS 或 SMIL 动画引用的 `id`、`class`、`<defs>` 不能被压缩工具删掉或改名；压缩后要实际播放动画确认。

### 6. 小尺寸看不清

**适用范围**：图标。在 16px / 24px 等目标尺寸预览，删掉小尺寸下看不清的细节，必要时为小尺寸单独做简化版。

## 工作流建议

- 简单图标：直接让模型按上面约束写 SVG 代码，再跑压缩工具；单色图标再转 currentColor。
- 图标集：统一 viewBox、stroke 规则、颜色策略，批量处理后逐个抽查。
- 复杂图形：可以先用支持原生矢量输出的工具生成，再人工简化路径；具体工具请自行核验当前能力。
- 动画 SVG：确认动画真的在跑（例如鹈鹕骑车时腿是否跟着踏板），只看一帧不算验收。

## 验收

在目标尺寸和目标背景（亮/暗）下看；压缩前后对比外观；动画 SVG 实际播放。
